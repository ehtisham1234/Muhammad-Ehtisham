1. Connect your channel

This runs entirely in your browser using the official YouTube Data API v3. Your API key is stored only in your browser's local storage and is sent directly to Google's API — never to any third-party server.

  1. Go to the Google Cloud Console, create/select a project, and enable the "YouTube Data API v3".
  2. Create an API key under Credentials (restrict it to the YouTube Data API for safety).
  3. Find your channel's handle (e.g. @yourhandle) or channel ID from your channel's "About" page.

2. Connect Google account for watch hours (optional)

View/like/comment counts are public, but watch time is private to you. Seeing it requires you to sign in with Google and grant read-only access to your own YouTube Analytics. Nothing is sent anywhere except Google's servers — this page has no backend.

  1. In the same Google Cloud project, go to "APIs & Services > Credentials" and create an OAuth 2.0 Client ID of type "Web application".
  2. Add the URL you're opening this page from (e.g. http://localhost:8000) to "Authorized JavaScript origins".
  3. Enable the "YouTube Analytics API" for the project.

    Growth checklist

    Tactics that reliably move likes and subscribers — all within YouTube's terms of service.

    • Ask explicitly, once. A short, specific call-to-action ("if this helped, hit like — it takes one second") near a payoff moment in the video outperforms generic outros.
    • Hook in the first 15 seconds. State the payoff up front; retention in the opening seconds is the single biggest driver of how widely YouTube distributes a video.
    • Thumbnail + title as a pair. The thumbnail should show a moment or emotion, the title should create a question — together they should promise one clear thing.
    • Pin a comment. Pin a question related to the video to prompt replies; comments boost the video in recommendations.
    • Use end screens and cards. Point to your next-best video, not just "subscribe" — that keeps session time up, which YouTube rewards.
    • Post on a consistent schedule. Even one video every two weeks, always on the same day, trains the algorithm and your audience.
    • Use the Community tab between uploads to keep subscribers engaged without needing a full video.
    • Study your Audience Retention graphs (YouTube Studio > Analytics > Engagement) for the exact timestamp viewers drop off, and fix that moment in your next edit.

    Data source: YouTube Data API v3. No engagement is purchased, automated, or faked — this tool only analyzes your real numbers and suggests content improvements.
